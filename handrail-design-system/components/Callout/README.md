# Callout

Pulls one rule out of the running text and says how firm it is.

**The consumer provides** `kind` (`required`, `recommended` or `note`), an optional one-line `title`, and `children` (one or two short paragraphs).

- `required` sits on `rail-soft` with a `rail-deep` top rule. Use it for rules with consequences. More than two per page and nothing feels required.
- `recommended` is a `line-strong` top rule on the page ground. Use it for good practice.
- `note` sits on `sunken`. Use it for context that helps but changes nothing.
- The top rule runs the full width. Never use a colored bar down the left side.
