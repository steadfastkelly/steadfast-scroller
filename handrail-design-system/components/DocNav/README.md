# DocNav

The handbook's table of contents, grouped by team or area.

**The consumer provides** `sections`, each a `title` and `items` (`label`, `href`, `active`, `status`).

- The active page gets the `rail-soft` highlighter, like marking a page in a printed binder.
- Only pages that need attention show a badge (`review`, `draft`, `overdue`). Approved pages stay quiet.
- Docked at `nav-width` (272px) from 1080px up. Below that it moves into a menu sheet.
- Group titles use `label`. Keep groups to the teams people actually ask for, not the org chart.
