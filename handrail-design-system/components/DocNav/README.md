# DocNav

The handbook's contents, grouped by team, inside its own tile.

**The consumer provides** `sections`, each a `title` and `items` (`label`, `href`, `active`, `status`).

- Group titles are `Eyebrow`s with a real count: `People Ops (04)`.
- Items are `ink-muted` pills that turn `ink` on hover. The active page sits on `rail-soft`.
- Only pages that need attention get a badge. Approved pages stay quiet.
- Docked at `nav-width` from 1200px. Below that it opens as a sheet from the top bar.
