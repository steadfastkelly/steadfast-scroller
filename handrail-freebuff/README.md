# Handrail design system for Freebuff

1. Put this whole `handrail-design-system` folder at the root of your Handrail project.
2. Copy `knowledge.md` to the project root too (or keep it here; Freebuff reads knowledge.md files in subfolders as well).
3. Start Freebuff in the project and tell it: "Read handrail-design-system/knowledge.md and use it for all UI work. Import handrail-design-system/handrail.css at the app root."

Open `reference/handbook-page.html` in a browser to see the target, and resize the window to check each layout.
